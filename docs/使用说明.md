# 番茄发文助手 使用说明

## 项目用途

本工具用于将本地小说章节批量上传到番茄作者后台。

当前正式版本支持：

- 本地多书目录
- 每本书多卷目录
- `md` / `txt` 章节文件
- 同步后台书库、卷、章节
- 右侧章节对比后手动勾选上传
- 使用登录态进行静默上传

---

## 环境前置条件

请先确保本机已安装可用的 Python 3 环境。

首次部署前，先执行以下命令：

```bash
# 安装核心依赖
pip install playwright pillow

# 下载 Playwright 需要的内置 Chromium 浏览器内核
playwright install chromium
```

如果你使用虚拟环境，先激活虚拟环境后再执行上述命令。

## 本地小说目录要求

草稿来源目录必须是“多本书根目录”或“单本书目录”。

### 推荐结构：多本书 + 多卷

```text
mybook/
  余烬循环/
    第1卷/
      第001章_穿越·裂缝吸入.md
      第002章_孵化·蛋中觉醒.md
    第2卷/
      第021章_追踪·丛林深处.md
  第二本书/
    第1卷/
      第001章_开局.md
```

### 兼容结构：单本书 + 多卷

```text
余烬循环/
  第1卷/
    第001章_穿越·裂缝吸入.md
  第2卷/
    第021章_追踪·丛林深处.md
```

### 兼容结构：单本书 + 单目录章节

```text
余烬循环/
  第001章_穿越·裂缝吸入.md
  第002章_孵化·蛋中觉醒.md
```

### 文件要求

- 支持扩展名：`md`、`txt`
- 文件名建议包含章节号，例如：
  - `第001章_穿越·裂缝吸入.md`
  - `第12章 冲突升级.txt`
- Markdown 文件第一行建议直接写章节标题，例如：

```md
# 第12章 冲突升级
```

### 注意

- 草稿来源目录是唯一数据源
- 不再使用归档目录
- 上传成功后，本地文件不会自动移动或删除

## 登录凭证说明

程序依赖本地登录凭证：

- `data/state.json`

如果首次运行没有凭证，需要先登录。

可用方式：

### 方式 1：从 GUI 中登录

- 打开程序后点击登录按钮
- 在弹出的浏览器中完成番茄作者后台登录
- 确认后程序会自动保存登录凭证

### 方式 2：手动执行登录脚本

```bash
python3 login.py
```

登录成功后会生成或更新：

```text
data/state.json
```

## 启动方式

### 启动主程序

```bash
python3 main_webview.py
```

如果当前没有有效登录凭证，主程序会在界面内提示登录，无需先单独执行 `python3 login.py`。

### 单独获取登录凭证

```bash
python3 login.py
```

这一步是可选项，适用于：

- 你希望先单独完成登录授权
- 主界面内登录流程需要手动重试
- 你只想更新 `data/state.json`

## 使用流程

### 1. 启动程序

执行：

```bash
python3 main_webview.py
```

### 2. 完成登录

如果当前没有有效登录凭证，先点击登录并完成授权。

### 3. 同步本地书库

在左侧 `本地书库` 卡片中：

- 选择草稿来源目录
- 点击 `同步本地书库`
- 选择本地书
- 选择本地卷

### 4. 同步后台书库

在左侧 `远端书库` 卡片中：

- 点击 `同步后台书库`
- 选择后台书
- 点击 `同步卷和章节`
- 选择后台目标分卷

### 5. 检查右侧章节对比表

右侧会显示当前本地章节和后台章节的对比状态。

你可以：

- 查看全部章节
- 只看待上传章节
- 只看冲突章节
- 只看已匹配章节

### 6. 勾选需要上传的章节

可用操作：

- `仅选可上传`
- `清空`
- `选待上传前 X 章`

### 7. 开始上传

- 点击 `上传选定章节`
- 在确认弹框中确认
- 程序会自动静默上传

---

## 章节对比状态说明

### 可上传

远端不存在该章节，可以直接上传。

### 已上传且匹配

远端已有该章节，且章节号和标题匹配。

这类章节只展示，不可勾选。

### 已上传但标题不一致

远端已有该章节，但标题和本地不一致。

这类章节用于检查差异，不参与上传。

## 日志查看

日志默认不常驻在主界面。

查看方式：

- 点击右侧章节对比表右上角的终端图标
- 弹出日志窗口后查看详细运行过程
- 可以在日志窗口中清空日志

## 常见问题

### 1. 选择目录没有反应

请确认：

- 程序已重启到最新版本
- 点击的是左侧 `本地书库` 卡片中的 `选择目录`
- 日志窗口中是否有点击日志

### 2. 同步后台书库失败

优先检查：

- `data/state.json` 是否存在
- 登录状态是否失效
- 当前网络是否能正常访问番茄作者后台

### 3. 章节明明已经上传，右侧仍显示待上传

优先操作：

1. 重新点击 `同步卷和章节`
2. 切换一次本地卷
3. 再切回目标卷重新查看

### 4. 上传成功后本地文件没有变化

这是当前版本的正常行为。

当前正式版不会：

- 自动归档
- 自动移动文件
- 自动删除文件
