# 番茄发文助手 使用说明

## 适用范围

本项目当前版本适用于：

- 本地多书目录
- 每本书多卷目录
- `md` / `txt` 章节文件
- 番茄作者后台同步书籍、卷和章节
- 在 GUI 中多选章节后上传

当前推荐的本地目录结构：

```text
mybook/
  余烬循环/
    第1卷/
      第001章_穿越·裂缝吸入.md
      第002章_孵化·蛋中觉醒.md
    第2卷/
      第021章_追踪·丛林深处.md
```

## 使用流程

1. 运行 `python3 main_webview.py`。
2. 如首次使用，先点击登录获取后台凭证。
3. 在左侧 `本地书库` 卡片中选择草稿来源目录，并点击 `同步本地书库`。
4. 在左侧 `远端书库` 卡片中点击 `同步后台书库`。
5. 选择后台目标小说，再点击 `同步卷和章节`。
6. 选择后台目标分卷、本地书、本地卷。
7. 在右侧章节对比表中勾选待上传章节。
8. 点击 `上传选定章节`，确认后开始上传。

## 章节对比状态

- `可上传`：远端不存在该章节，可以直接上传。
- `已上传且匹配`：远端已有该章节，且标题匹配，不可选。
- `已上传但标题不一致`：远端已有该章节，但标题不同，仅用于查看，不参与上传。

## 批量操作

右侧章节对比表支持：

- `仅选可上传`
- `清空`
- `选待上传前 X 章`
- 视图切换：
  - `全部`
  - `待上传`
  - `冲突`
  - `已匹配`

## 日志查看

日志默认不常驻显示。

- 点击右侧表头区域的终端图标打开日志弹框。
- 日志弹框中可以查看和清空日志。

## 登录凭证

程序依赖本地 `data/state.json` 作为登录凭证。

- 如果没有凭证，需要先完成登录授权。
- 登录成功后会生成或更新 `data/state.json`。

相关脚本：

- [login.py](/Users/jiangmiao/work_dict/aicode/fanqieAutoPublish/login.py)

## 注意事项

- 草稿来源目录是唯一数据源，不再使用归档目录。
- 上传成功后，本地文件不会自动移动或删除。
- 上传链路当前走页内上下文接口，不依赖中间网页编辑器点击流程。
- 如果同步后台书库或卷章节失败，先确认登录凭证是否有效。
- 如果章节对比不符合预期，优先重新同步后台卷和章节。
- 正式版目录已经移除抓包、PoC、测试脚本，只保留运行所需文件。

## 常见问题

### 1. 选择目录没有反应

请确认：

- 程序已重启到最新版本
- 点击的是左侧顶部的 `选择目录`
- 日志弹框中是否出现对应调试日志

### 2. 上传后没有立即看到状态变化

正常情况下，上传成功后右侧表格会立即更新为 `已上传且匹配`。

如果没有更新：

- 重新同步当前小说的卷和章节
- 再检查右侧章节状态

### 3. 后台章节已存在，但显示成待上传

这通常和章节号或远端目录缓存有关。

优先操作：

1. 同步后台卷和章节
2. 切换一次本地卷
3. 再回到目标卷重新查看
